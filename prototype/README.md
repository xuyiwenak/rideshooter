# 逐风骑手：局内成长灰盒

当前版本包含骑行、普通骑射、精英战、战意升级、6项技能和2条进化。仍不含Boss、正式美术和局外成长；左右自由移动没有加入。

工程已拆分为玩家、战斗、敌人AI、成长、世界和界面模块，维护入口见 [工程结构与扩展指南](ARCHITECTURE.md)。本轮使用原生GDScript，没有新增插件依赖。

## 打开与运行

已经打开工程：先停止旧游戏，再点击 ▶ 重新运行。只在旧游戏里按 R 不会加载新版代码。

1. 在Godot项目管理器点击“导入”。
2. 选择仓库中 `prototype/project.godot`。
3. 选中导入后的项目，点击“编辑”。在编辑器点右上角的 **▶运行**；如果游戏在编辑器内嵌运行，点顶部“游戏”标签即可看到画面。Mac键盘的F5可能是系统功能键，直接点▶最省事。

## 操作

| 按键 | 动作 |
|---|---|
| W/S 或方向键上下 | 换道 |
| Space | 跳跃 |
| Shift 或 E | 冲锋 |
| R | 重新开始 |
| F2（Mac可能需要 Fn+F2） | 直接进入精英练习 |
| F1（Mac可能需要 Fn+F1） | 返回完整道路流程 |
| 数字键1/2/3 | 升级界面选择对应卡牌 |
| F3（Mac可能需要 Fn+F3） | 重开并直接装备箭雨进化 |
| F4（Mac可能需要 Fn+F4） | 重开并直接装备铁骑进化 |

每局3点生命，道路长度相当于基础速度行进60秒；Road显示剩余路程折算值。冲锋加快道路推进，到中点（Road 30）遭遇精英，进度暂停，击败后继续。实际局长取决于冲锋次数、选卡和精英战耗时。练习模式击败精英即结束，R重开同一模式。原有换道、跳跃、冲锋持续时间和冷却不变。

地面、花草、石块向后移动，灌木与山体分层慢移，太阳固定。冲锋时道路平滑加速至基础速度的1.8倍，普通怪和路障相对接近也加快；玩家横坐标不变，攻击预警与技能冷却不加速。

## 战斗规则

- 每0.55秒自动发箭：优先本车道前方最近目标，伤害1；没有本车道目标时攻击相邻车道，伤害0.5。隔两条车道不攻击，箭发出后不追踪。
- 普通怪头顶金色小圆点是当前优先目标，浅黄色箭是自己的，红色箭是敌人的。
- 红色步兵生命3，接近时脚下亮橙色警示，接触扣血；可射杀、换道、跳跃或冲锋。
- 紫色弓手生命2，橙色瞄准线锁定你当时所在车道，预警0.85秒后射一箭；可提前换道、跳跃或击杀应对。
- 橙色追击兵生命3，比固定怪接近更快。距离足够时先用黄色方向线预告0.35秒，再用0.42秒向玩家方向移动一个相邻车道；目标锁定后不临时追踪，近身不再发起换道。
- 冲锋期间免伤，接触可撞杀普通敌人、撞碎拒马；对精英不是秒杀。
- 普通敌人被越过后变暗离场，停止攻击并移除残留敌箭。漏怪不扣血、不算击杀。
- 玩家头顶三格表示生命，精英和普通怪的血条也跟随头顶。Kill是击杀数，CD是冲锋剩余冷却。受伤后保护0.9秒。
- 每6个基础路程秒生成一组，依次为固定怪＋侧路追击兵、三车道错峰夹击、弓手＋追击兵＋路障。固定顺序便于比较操作；跨车道出现不等于同时封死三路。
- 冲锋全程0.48秒免伤，可躲敌箭、投矛和接触攻击，期间不消耗护盾；仍保留撞怪和道路加速。完整Boss及两路/三路技能尚未实现。

## 精英骑兵

1. 骑兵先奔驰接近，根据距离、车道、动作冷却和近期招式，选择冲撞、投矛或换位，不再只有固定冲撞循环。
2. 红色整道警示持续0.9秒，随后沿锁定车道冲锋，不再追踪你的换道。
3. 换道或跳跃可避开；及时按冲锋对冲可免伤并打掉精英4点生命，每次敌方冲锋只结算一次。
4. 冲锋结束后退回前方，变绿进入1.8秒硬直；成功对冲则延长至2.4秒。此时箭伤提高50%，适合回到同道输出。
5. 灰蓝色是无接触伤害的退回/回位阶段，然后开始下一轮攻击。
6. 紫色瞄准线表示投矛：锁定当时车道，预警0.95秒后发射一次。预警之后换道，矛不会改道追踪。

精英生命24，不随背景滚出画面。精英期间不刷新普通怪，旧怪自然离场，背景照常滚动；击败后恢复道路进度与刷新。全程最多遭遇一次精英。练习模式不夹杂普通怪。

## 战意与三选一

- 普通敌人提供1点战意，精英提供5点；战意自动进入顶部XP，不需要拾取。
- 升级需求依次增加：3、4、5……；溢出的战意保留。连续升多级时会逐次选卡。
- 选卡期间战斗、道路、预警和冷却全部暂停。使用数字键1、2、3或鼠标点击卡牌选择。
- 第一张卡偏弓箭路线，第二张偏战马路线，第三张是辅助能力，确保测试构筑时不被随机结果干扰。

| 能力 | I/II级效果 |
|---|---|
| 多重 | 每次自动射击增加1/2个额外目标 |
| 燃烧 | 命中附加持续伤害，II级持续更久、伤害更高 |
| 冲撞 | 对冲精英伤害由基础4提高到6/8 |
| 护盾 | 抵挡一次伤害，10/7秒后恢复 |
| 连射 | 自动射击间隔缩短至基础的82%/66% |
| 击杀回血 | 每6/4次击杀恢复1点生命 |

- 连续选择弓箭路线：多重I → 多重II → 燃烧I → 燃烧II，自动进化为“燎原箭雨”，燃烧箭覆盖最多三条车道。
- 连续选择战马路线：冲撞I → 冲撞II → 护盾I → 护盾II，自动进化为“铁骑冲阵”，冲锋时恢复护盾并提高对冲伤害。

## 试玩反馈

先用F3、F4在相同敌阵比较箭雨和铁骑，再按F1从零开始各走一次弓箭、战马路线。告诉我：两条路线是否明显不同；选卡频率是否合适；哪项升级看不出效果。

现在无需购买或生成素材。成长手感确认后，补卡池边界和进化保底，再制作Boss与完整结算流程。

## 自动检查

执行 `Godot --headless --path . --script res://tests/test_combat.gd`，将 Godot 替换成本机可执行文件路径。检查索敌、伤害、预警、离场、冲锋、重开与一分钟敌阵调度。

精英、成长、集成与追击兵检查：分别执行 `--script res://tests/test_elite.gd`、`--script res://tests/test_growth.gd`、`--script res://tests/test_integration.gd`、`--script res://tests/test_raider.gd`。检查数分别为基础18项、精英19项、成长19项、集成17项、追击兵与免伤15项，总计88项。`preview_elite.gd`、`preview_growth.gd` 与 `preview_raider.gd` 用于实际渲染截图检查。
