# 测试与预览入口

- test_combat.gd：基础战斗、索敌、弓手、离场、冲锋和调度。
- test_elite.gd：精英预警、反击、练习与关卡衔接。
- test_growth.gd：战意、选卡、技能、进化和重开。
- test_integration.gd：模块信号、暂停、清理、速度、决策与完整流程。
- test_raider.gd：普通追击兵、多路阵型、免伤及护盾边界。
- test_run_config.gd：默认/自定义 Resource、击杀奖励和升级溢出、波次/精英时点、完整道路的理论刷怪与成长预算。
- preview_elite.gd / preview_growth.gd / preview_raider.gd：带图形运行，截图保存 user://；实际路径以脚本输出为准。

测试从 main.tscn 实例化，不绕过真实场景组合重新拼一个假工程。测试准备可关闭自动 _process 并显式推进；必须明确哪些状态被人为设置。

新增行为先覆盖边界：预警与锁定、单次伤害/奖励、死亡/离场、暂停恢复、重开清理。不要为了通过测试删断言或掩盖错误；玩法有意变化时同步对应预期并记录理由。

test_horse.gd 覆盖真实主场景的马匹动画与烟尘暂停、跳跃/落地、冲刺、换道和重开；preview_horse.gd 原生截图。

test_rider_animation.gd新增18项，覆盖四动作出箭、连射、目标消失、皮肤、暂停重开；preview_rider.gd输出四姿势、上路跳跃及运行序列。

最近代码基线五组 18+19+20+17+15=89 项，马匹10项，骑手动画18项，配置专项14项，另有敌人美术27项，总计158项；新增测试后以实际输出为准更新记录。配置专项的全清预算是脚本推演，不代表真人难度合格。完整流程测试会补生命，同样不能据此声称难度合格。测试修改也按根规则写日期版本记录。

- test_enemy_art.gd：四类透明Atlas/脚底对齐、全部跑帧、碰撞锚点、弓手实际出箭、精英姿势映射、暂停/死亡/结束/重开27项。
- preview_enemy_art.gd：真实main场景的人工排布合影、精英三状态及72帧运行序列；提高敌人HP只为验收。对普通怪血条进行截图像素断言。

- test_archery_feedback.gd：真实齐射/命中/击杀事件、位置、无命中/离场、声音/视觉暂停、重开、并发限制与回收20项。
- preview_archery_feedback.gd：120帧真实主场景，记录三类反馈及AudioEffectRecord原生混音。首目标标准HP，后半箭雨目标1HP，关闭选卡用于验收。
- 涉及快速反复播放/重开的测试在free主场景后留0.1秒给AudioServer回收播放实例，再quit，避免提前结束音频线程。
- test_licensed_audio.gd：本机7段Ovani声音导入、事件映射、马蹄/环境暂停、护盾、升级选卡、合成声回退和重开13项；当前全套191项。此测试要求先在本机导入授权音频，公开仓库克隆环境可跳过该专项，其余测试使用缺失素材回退。
