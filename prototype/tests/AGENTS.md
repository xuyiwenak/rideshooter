# 测试与预览入口

- test_combat.gd：基础战斗、索敌、弓手、离场、冲锋和调度。
- test_elite.gd：精英预警、反击、练习与关卡衔接。
- test_growth.gd：战意、选卡、技能、进化和重开。
- test_integration.gd：模块信号、暂停、清理、速度、决策与完整流程。
- test_raider.gd：普通追击兵、多路阵型、免伤及护盾边界。
- preview_elite.gd / preview_growth.gd / preview_raider.gd：带图形运行，截图保存 user://；实际路径以脚本输出为准。

测试从 main.tscn 实例化，不绕过真实场景组合重新拼一个假工程。测试准备可关闭自动 _process 并显式推进；必须明确哪些状态被人为设置。

新增行为先覆盖边界：预警与锁定、单次伤害/奖励、死亡/离场、暂停恢复、重开清理。不要为了通过测试删断言或掩盖错误；玩法有意变化时同步对应预期并记录理由。

最近代码基线五组 18+19+19+17+15=88 项；新增测试后以实际输出为准更新记录。完整流程测试会补生命，不能据此声称真人难度合格。测试修改也按根规则写日期版本记录。
