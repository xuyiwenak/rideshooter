# 骑手设计草案 · 大头、稳定骑姿、可替换皮肤

日期：2026-09-24。状态：A骑手分层贴图与四动作已接入Demo。实际文件、尺寸和限制以[运行资源说明](runtime/characters/rider/README.md)为准。下方保留设计目标，B/C皮肤、完整远侧镫和精修补间尚未交付。

## 参考依据与边界

用户提及“两个王国”，本轮按《王国：两位君主 / Kingdom Two Crowns》理解。

- [官方游戏页](https://kingdomthegame.com/kingdom-two-crowns/)：确认横向卷轴、现代像素风与骑乘君主表现，并有不同主题的人物与坐骑。
- [开发者在PlayStation Blog的介绍](https://blog.playstation.com/2020/04/17/kingdom-two-crowns-dead-lands-gets-a-bloodstained-crossover-on-april-28/)：Dead Lands中可解锁切换四位不同君主及坐骑；这些角色有独特能力，不能将其直接当成“纯外观皮肤系统”的证据。
- 以下分层、比例、坐标及动画方式是本项目设计建议，不是对该游戏内部素材或代码结构的断言。没有提取或复制该游戏人物素材。

## 外观方向

参考横向骑乘角色的清晰轮廓与紧凑骑姿。主角头部较原占位圆头更醒目，脸、发型、头饰承担身份识别；身体形态统一，方便动作复用。

[设计对照图](concepts/rider_skin_concepts.png)的三款均是候选，尚未由用户定稿：

- A（推荐基础款）：乱发、赭红头巾、扬眉和自信小笑脸；蓝绿色短衣、棕裤靴。颜色与棕马/金饰有分离。
- B：小歪王冠，保留大部分头发、眼睛与眉毛，作为搞笑国王皮肤。
- C：反戴紫帽、小耳环，作为街头皮肤；避免墨镜遮住全部表情。

搞笑主要靠表情、头饰与小配件，身体保持正常骑姿。臀部贴鞍，髋部稳定，大腿斜向前、膝盖弯曲，小腿位于马腹侧，前脚掌踩入马镫；冲刺适度前倾。不要站在马背、双腿笔直垂下，也不要身体随每个跑帧大幅上下拉伸。

## 尺寸建议（必须在主游戏实测后定稿）

现有内部画面480×270，马使用72×72虚拟画布、可见宽约63–69像素；三条车道中心间距61像素。

| 项目 | 建议游戏像素 | 理由 |
|---|---|---|
| 头部含普通头发 | 18×18左右 | 比现有直径14的占位头突出，仍留车道空间 |
| 常规头饰上限 | 22×22左右 | 帽檐/小王冠识别；特大帽子需要单独验收 |
| 肩宽 | 12–14 | 头宽约肩宽1.3倍，避免大头完全压住身体 |
| 躯干高度 | 14–16 | 精简衣服细节，保留姿势 |
| 整体从帽顶到马蹄 | 约60–65 | 逐帧检查相邻车道、顶栏、血条与跳跃遮挡 |

这些不是从概念图自动裁切得到的数值。概念图细节比实际画面多；制作时需以目标尺寸像素轮廓重新整理，不把高清图直接缩小作为最终品质保证。使用nearest采样。

## 换皮肤结构

先做“整套皮肤切换”，内部保留头部独立替换能力；暂不做任意衣裤装备排列组合。头变大只改善辨识度，真正降低换皮成本的是共享坐标、动作和挂点。

| 部件 | 内容 | 复用约束 |
|---|---|---|
| head | 头部＋头发＋头巾整体制作，与身体分离 | 所有皮肤用同一个颈部连接点；允许表情帧 |
| body | 短衣、坐姿髋部、近侧腿与靴 | 相同肩部、髋部及脚蹬位置；靴底与马镫接触，体型相近的皮肤共用动作 |
| arms | 持弓臂、拉弦臂，手与弓柄对齐 | 独立于马跑帧，按实际射击状态驱动 |
| weapon | 弓、箭、背部肩囊/箭袋作为一套配套装备制作 | 运行时按遮挡分层；固定握柄、弦上搭箭点、出箭点及背后取箭点 |
| back（装备后层，可空） | 背在后背的肩囊/箭袋，归属弓箭装备套件 | 没有素材或未装备时留空，不烘焙到身体/头部；箭袋开口须供手触及 |
| stirrups | 马镫、镫带，归属鞍具 | 与鞍点及左右脚蹬连接；近远层分开，不能随鞋皮肤改变位置 |

概念上的绘制顺序：后置配件/远侧腿 → 马 → 骑手身体与近侧腿 → 头 → 持弓手及武器；手与弓的遮挡在样机中确认。视觉层保持局部独立，不用新皮肤复制整份玩家或攻击脚本。

## 马与骑手的连接

当前马图集只做了脚底对齐，各帧背部仍有高度/形状变化。必须逐帧标定6个鞍点，不能只给骑手一个固定位置或用独立正弦抖动凑效果。

- 统一以马脚底/玩家现有ground_y为地面基准。
- 骑手的seat连接到当帧鞍点，头、身体与手臂随之整体平移，避免头和身体错位。
- 主要连接点为头、肩、臀、脚蹬：head/neck连接头部，shoulder_near/shoulder_far驱动双臂，seat固定臀部，stirrup_near/stirrup_far固定两侧脚蹬。脚蹬属于马鞍系统，脚部贴合脚蹬，不独立摆荡。
- 镫带从鞍具垂下；靴子的前脚掌踩镫，膝部保持弯曲。马步、跳跃、冲刺时用同一组鞍点变化传递到臀与镫，避免脚在空中滑动或镫带脱离。
- 辅助装备挂点：back_mount（背部肩囊/箭袋）、quiver_pick（箭袋开口）、grip（弓柄）、string_nock（弦上箭尾）、bow_release（飞行箭起点）。皮肤可以带小偏移，但不能决定碰撞。
- “一起制作”指弓、箭、背部装备在尺寸/动作上配套，不是把它们合成一张不能分层的贴图。没有背部装备素材时留空挂点；动作草稿仍须标出取箭接触点，正式动画不得表现为凭空出现一支箭。
- 先只做小幅整数像素起伏，检查6帧坐姿。如果需要大幅移动，优先修马图集背部，不用夸张骑手弹跳掩盖。
- 新骑手更高，血条相对角色顶部调整并继续在UI层绘制；上车道跳跃需专项截图。

现已通过rider.arrow_origin读取Visual.muzzle，替代旧硬编码(+23,-22)，并覆盖跳跃偏移和出箭位置检查。

## 动作第一批

1. ride：中性持弓、坐姿稳定；跟随6个马鞍点。不是每换一套衣服就重画人马合成图。
2. shoot：背后抓箭 → 搭箭上弓 → 拉弓 → 撒放 → 再抓箭，按下节四个主要动作循环制作。
3. sprint：躯干轻微前倾、头跟随、短头巾向后；射击可继续叠加，脚仍贴鞍侧。
4. jump：膝部保持夹紧、身体略前倾；落地短促回弹，后续再精修专用动作。
5. hurt：短暂表情/闪烁，不中断攻击计时，不凭动画重复扣血。

所有视觉时间从main的统一step派发；选卡、死亡、结束冻结，重开清空。跳跃/冲刺控制基础姿态，射箭控制手臂，受伤控制闪烁；不生成ride×shoot×skin的整张组合图集。

## 完整射箭动作分解（已按四动作接入）

[四动作设计板](concepts/rider_shoot_four_poses.png)已生成，顺序为抓箭、搭弓、拉弓、撒放；[生成记录](concepts/rider_shoot_four_prompts.md)。动作轮廓可供审阅，尚不是对齐后的透明分层动画。正式素材需统一身体位置、加强靴底与马镫接触。

按用户最新要求，射箭只分四个主要动作。头朝前，臀部坐稳、脚踩马镫，持弓手持续握弓。

| 动作 | 表现 |
|---|---|
| 抓箭 | 拉弦手伸到背后取箭 |
| 搭弓（搭箭上弓） | 手回到身前，把箭搭上弓弦 |
| 拉弓 | 持弓臂向前，拉弦手拉到脸侧 |
| 撒放 | 松弦出箭，手自然接回背后抓箭 |

循环：抓箭 → 搭弓 → 拉弓 → 撒放 → 抓箭。伸手、抽箭、转到身前及回位融在相邻动作的过渡中，不再单列动作或停顿。四个主要动作不等于强制只能有四张图片；先画四个清楚的关键姿势，只在播放不顺时补必要过渡帧。

连续射击周期沿用当前武器配置（基础0.55秒，连射I/II为0.451/0.363秒），各动作停留比例通过原速预览确定。本轮撤销此前10姿势及固定0.41秒首次前摇草案，暂不锁定细分时长。

### 出箭事件与状态

- 进入撒放动作时才生成飞行箭，同时隐藏手持/弓上的箭；一个周期触发一次齐射事件。多重/箭雨复用该事件，不能每画一帧就创建一支箭。
- 当前首次攻击先完成准备，基础约0.44秒后撒放，连续撒放间隔保持0.55秒；本轮已回归相关战斗/时钟检查。
- 无目标时不空射：未开始则中性骑姿；已持箭或满弓而目标消失则保留箭，等待可用目标/安全回落，不能下一轮又凭空取出第二支。撒放时再次确认目标有效。
- 射击状态与马的6帧跑步独立。冲刺/跳跃只叠加基础骑姿和装备位置；不会触发额外出箭。
- 选卡暂停冻结精确动作阶段、弦形及手持箭状态；重开清空射击周期。持箭贴图不是战斗实体，飞行箭仍由Combat管理。

## 第一批制作与验收顺序

先完成A基础骑手的目标尺寸分层资源与六帧鞍点预览，再验证一个仅换头部的B皮肤，证明动作复用确实成立；C保留候选。随后制作四动作射箭分解与慢速/原速循环，对齐实际撒放事件；最后补冲刺和跳跃细节。肩囊/箭袋与弓箭配套，有素材再显示，未制作时保留空挂点。

验收需同时看：480×270原尺寸辨识度、整数倍放大轮廓、六个马帧的臀部接触、近/远腿和马镫遮挡、臀部与脚蹬持续接触、背后取箭的手部接触及箭的连续性、满弓到撒放仅产生一次齐射、弓口与箭起点、三车道及上路跳跃、暂停重开、换皮不改变伤害和碰撞。设计图仅作选型，不等于此清单已通过。
