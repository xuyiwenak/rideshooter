# 骑射反馈试样

`archery_feedback.tscn`在main中作为独立节点实例化，使用原生GDScript绘制短命特效，无贴图或插件依赖。事件分工：

- AutoBow.released：真正创建齐射后发出一次，弓口130ms回弹白线及弦声；多箭只响一次。
- Combat.hit_confirmed：玩家箭扫掠碰撞并结算伤害后，在该段距目标最近的接触位置发出，220ms星芒/碎屑与打击声。未命中不触发；燃烧跳伤不重复触发箭命中特效。
- Combat.enemy_defeated：敌人死亡信号提供位置，380ms烟团/装饰碎屑与滑稽合成音；箭杀、燃烧或冲撞都只结算一次，离场不触发。
- Rider.shield_blocked：护盾实际消耗时播放格挡声及220ms蓝色圆环；冲锋免伤和普通受伤不冒充格挡。
- WarSpirit.upgrade_opened / choice_confirmed：升级奖励与有效选卡播放UI声。选卡暂停期间UI声仍可响。

箭尾短拖线仍由Arrow绘制，不播放持续飞行声。Enemy沿既有hit_flash做短暂提亮与10%压缩回弹，脚底固定；不改变碰撞和生命值。视觉碎屑不是可拾取装备。

main统一step推进特效寿命；选卡、玩家死亡或道路结束暂停特效与玩法AudioStreamPlayer.stream_paused，恢复后继续。马蹄与草地循环声也随此时钟启动、暂停和重开；跳跃停马蹄，冲锋提高音调。重开停止声音、清空特效及计数。节点退出时停止播放并释放stream引用。

最多48个短命视觉事件，6个固定战斗短声通道；额外2个UI声及2个循环声通道。合成声音每类3个变体顺序轮换；本机授权声也小幅变调。撒放组45ms间隔，命中/击杀/护盾组65ms间隔；战斗通道满时跳过声音，不叠加无限播放。导入与版权说明见[音效说明](../../audio/sfx/README.md)。

这是第一版反馈：没有震屏、受击停顿、持续飞行噪声或真人怪叫。敌方投矛和玩家掉血声音尚未制作。先前原生截图/GIF与合成声音混音在asset/concepts/；新授权声的实际混音仅留在本机 Godot `user://archery_feedback_mix.wav`，不放入公开仓库。预览人工安排敌人且关闭选卡，后半段用箭雨与1HP目标，不代表正常关卡录像。
