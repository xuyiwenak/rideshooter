# 道路、远景与出怪

- road.gd / road.tscn：唯一道路速度与滚动距离来源、路障和近景花草。
- scenery.gd / scenery.tscn：读取道路距离做分层远景；太阳固定，不另建独立世界速度。
- encounter_director.gd：路程进度、出怪组、车道分配、精英中点与结束条件。
- Road 数值是按基础速度折算的剩余路程，不是墙钟倒计时。
- 冲刺影响路程与普通敌人相对接近，不加快预警/技能冷却。
- 精英战暂停路程和普通怪生成，但背景继续移动；选卡则统一暂停。
- 多路阵型错峰接近，攻击有可读预警；不要无预告同时堵死所有生存路径。
- 验证 test_combat、test_integration、test_raider；精英调度变化追加 test_elite。场景改动要看原生渲染。
